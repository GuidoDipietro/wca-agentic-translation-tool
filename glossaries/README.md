# Bundled glossaries

Place reviewed UTF-8 JSON defaults here, named with the lowercase language code and underscores, for example `es_419.json` or `pt_br.json`. No language glossaries are shipped yet.

See [the README](../README.md#language-glossaries) for the schema, validation/import commands and a suggested corpus-based authoring prompt. Files in this directory are versioned defaults; personal replacements live in the selected data directory's `glossaries/` folder and are not committed.
